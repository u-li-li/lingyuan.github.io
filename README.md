# Lingyuan — Personal Academic Website

A responsive one-page website for an early-stage PhD student, built with semantic HTML and CSS for GitHub Pages.

## Sections

- Profile and short introduction
- Research
- Selected Publications

The Scholar and CV destinations, along with Selected Publications, are intentionally blank until they are ready to be added.

## Edit the site

- Update copy in `index.html`.
- Adjust colors and layout tokens at the top of `styles.css`.
- Add publications later as a new section when needed.

## GitHub Pages

Serve the site from the `main` branch and repository root in the repository’s Pages settings.
